# Roadmap Futuro: Mis Arroces

## DIRECTOS V1 — INTEGRACIÓN EXTERNA
**Estado:** ROADMAP FUTURO. NO BLOQUEA LANZAMIENTO.

**Objetivo:** Permitir que un usuario anuncie y muestre dentro de misarroces un directo que esté realizando mediante una plataforma externa (inicialmente YouTube Live).

**Concepto futuro:**
- El usuario podrá vincular un directo.
- misarroces podrá mostrar que ese usuario está "EN DIRECTO".
- Sus seguidores podrán descubrir que está emitiendo.
- El directo podrá visualizarse dentro de misarroces mediante reproductor integrado cuando las condiciones de la plataforma externa lo permitan.
- Podrá existir acceso desde perfil/feed u otras superficies.
- Podrán existir notificaciones a seguidores cuando comience un directo.
- La infraestructura de streaming y distribución de vídeo NO será inicialmente de misarroces.

**Objetivo de V1:** Validar si existe demanda real de directos relacionados con elaboración de arroces, recetas, cocina en vivo, eventos, demostraciones y contenido de creadores.

## DIRECTOS V2 — NATIVO
Solo se estudiará si Directos V1 demuestra uso suficiente. Se evaluará streaming nativo mediante proveedor especializado (Amazon IVS, Mux, Agora, etc.).

**Posibles características V2:**
- iniciar directo desde misarroces;
- espectadores dentro de misarroces;
- chat en directo;
- reacciones;
- moderación;
- notificaciones;
- replay;
- métricas para el creador.

**Decisión basada en:** uso real de V1, audiencia media, frecuencia de emisión, coste por emisión/espectador, necesidades de moderación y escalabilidad.
